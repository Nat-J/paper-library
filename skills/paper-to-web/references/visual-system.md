# RoboTTT 导读的视觉系统

目标是有编辑节奏的学习长页：安静、宽敞、技术信息可读。细边框、少量浅色面板、清楚的编号与箭头；不要变成营销首页或将每个句子塞进同等大小的卡片。

## 页面骨架

- 顶栏：小型大写研究主题，论文/项目/打印入口。
- 首屏：左侧大号论文简称与中文主张；右侧简短直觉和关键词。不要把完整英文长标题挤成超大字。
- 阅读路径：少量问题导向锚点；正文早期出现整体 pipeline。
- 章节：`00 / 01 / …` 编号、问题型标题、一段 lead、关键图/交互、解释、近处来源。主章节可以有浅色底和柔和主题色；内部卡片圆角约 5–8px，章节容器可更圆。
- 正文最大约 **1840px**，左右内距 `clamp(12px, 2.25vw, 44px)`。没有占宽的常驻侧栏。纯长段文本可设约 65–80 字符行宽，图表不受此限制。
- 左下圆形 **目录** 约 60px；展开约 310px 面板，内部滚动，点击章节自动收起，支持关闭/Escape/外部点击。右下是日间/夜间按钮；两者不可压住文章末尾。
- 顶部细阅读进度条；目录当前章节高亮；窄屏目录球约 56px。

## 字体、颜色与密度

中文用系统无衬线，标题/关键数字可用系统衬线点缀，不依赖远程字体。底稿的颜色是根据保留截图重建的接近值，非完整原 CSS 的逐像素复制。

| 角色 | 日间建议 | 夜间建议 |
| --- | --- | --- |
| 页面 | 淡灰绿 `#f3f6f2` | 深绿黑 `#101b18` |
| 内容底 | 暖白 `#fffefb` | 深橄榄 `#282518` |
| 正文 | 墨绿 `#233b30` | 灰白 `#dce6df` |
| 辅文 | 灰绿 `#617267` | `#b1c0b6` |
| 主色 | 深绿 `#285641` | 浅薄荷绿 `#a4cfb9` |
| 点缀 | 棕金 `#a77c42` | 淡金 `#d4b481` |

正文约 16–17px、行高 1.85–1.95；章节标题约 26–30px；辅助说明 13–14px。首屏大标题约 66–108px，窄屏缩小；避免长标题溢出。大数字和标题有留白，技术图中的文字保持可读字号。

语义配色稳定但按论文改名：蓝＝感知/输入，金＝状态或条件，青＝承载信息的 tokens，蓝紫＝融合，绿＝记忆/学习，紫＝生成输出，红＝门控/损失等特殊运算。**这些是参考网页的分类，不是所有论文必须具备的模块。**只使用需要的几类，并在图前给图例；颜色必须伴随名称/图标，不能独自承载意义。夜间模式为语义面板使用深底与足够亮的文字，原始图片和官方动画不做反色。

## 图与交互

- 总览图可点击跳到详细解释；完整路径有箭头。依赖明确后再选择网格，不能先排框再猜连线。
- 多支输入汇合应有真正的汇合点；同一步计算与环境反馈分道。复杂图优先少交叉的正交连线，重画后检查每一条边的起止。
- 变量一行一张横卡。默认左侧约 40–45%、右侧 55–60%，按内容调整；移动端堆叠。不要用等高大框堆出空洞图。
- 公式有可点符号和始终可见的核心解释。使用按钮/`details`，悬停提示只是补充；触屏和键盘也能读。
- 每个交互只有一个解释目标：前后条件切换、步骤推进、符号说明、原片选段等。切换状态立即可见，有标签和 `aria-pressed` / `aria-live` 等适当语义。
- 原图/官方动画紧跟中文读图提示。视频允许播放控制与倍速，懒加载，大资源不预载。样例数据与实测数据视觉上明确标识。

## 验收画面

至少检查宽桌面（如 1440px）和窄手机（如 390px）：标题不溢出，图中文字可读，局部横向滚动不带动整页，目录球与主题按钮不重叠，展开面板不出屏。夜间图例和变量卡片仍易读。键盘能操作控件，减少动画偏好生效，关闭 JS 后仍能阅读主文；打印隐藏浮层与按钮并展开重要解释。
