# 内容与证据规范

## 解释到哪一层

读者需要同时拿到直觉和技术落点。用同一个具体例子贯穿问题、pipeline、变量、训练样本和结果。先说对象及作用，再给英文名称与符号，不以术语替代解释。

“特征”“状态”“上下文”“对齐”“记忆”出现时，按论文说明它们指向的具体对象：图像、连续向量、文字、传感器数值、缓存、参数还是数据配对。不要把特征空间中的融合画成动作相加，也不要把“读到相关任务信息”直接说成几何动作映射。

对一个关键变量，能回答以下问题即够用：

- 它来自原始输入、另一个模块、随机采样，还是训练学到的参数？
- 是一个数、一串向量、一张矩阵、一段轨迹，还是一个网络？
- 形状中每个轴意味着什么，哪些精确数值原文未提供？
- 它被谁读、何时更新、何时重置？它跨越哪个时间/训练边界？
- 是预测值、拟合目标、监督标签，还是最终输出？

公式按“具体输入 / 标签 → 构造中间量 → 模型读什么、预测什么 → 目标从哪来 → 数字代入与误差 → 更新谁 / 下一步是什么”展开。至少用一个小数值例子走完关键运算，再对照原式；不能只列符号释义或重复“学方向、去噪”这类抽象短语。训练与推理分别说明已知信息：真实标签可参与构造监督，但不能流入推理流程。把向量简化为单个分量时标出简化范围，不把示意网络输出当成实测。较长推导可折叠。

先为当前论文确定一份视觉词典：图像帧、语言指令框、状态向量、动作块、示范标签、模型输出分别用什么符号 / 颜色 / 外形。总览、变量、公式、训练和时间轴复用它；改变采样时刻只改变下标，不改变视觉身份。教学图的相机视角、数值、token 块数和 raw/emb 等补充记号必须声明，不能写成论文规格。比喻之后说明适用范围。

## 时间与执行（适用时）

用有刻度的时间轴展示连续运动或序列执行，而非只列几个频率数字。动作块同时有“预测的跨度”和“真正采用的前缀”，两者画成对应但不同的部分。新的块何时发起、何时就绪、何时接管，各自是不同事件。

- 物理时间标秒 / 毫秒及动作间隔；长度 H、控制频率 f 的覆盖时长为 H/f，执行 m 步后的重预测间隔为 m/f。按论文本身的控制定义核对，不能把一次完整轨迹的覆盖时长误写成末帧时间戳。
- 内部迭代进度使用独立轴，例如归一化 τ 及积分步长；迭代次数不是 Hz。推理耗时与重新预测频率也分别标注。
- 异步方法增加模型计算轨和机器人执行轨，画出重叠、结果等待、过期前缀和切换事件。延迟补偿、拼接或聚合以该论文实际规则为准，不擅自补全。
- 忽略计算延迟的理想化窗口图、实测调度图、通用异步教学图明确区分。若论文只报告执行前缀和推理耗时，不把两者拼成一个假定的同步或异步实现。

## 数据与训练（适用时）

不要只写“在数据集上训练”。根据正文、附录和官方代码，尽可能填写：

| 问题 | 要显示的内容 |
| --- | --- |
| 数据来源与规模 | 数据集/任务、小时数/轨迹数/样本数、预训练与下游数据分别统计，划分及评估协议 |
| 一个样本长什么样 | 图像、状态、语言、动作或其他模态；成对关系、连续 clip、episode、采样窗口、拼接和顺序 |
| 谁监督谁 | 输入与标签分开；在哪些位置计算 loss，哪些只是上下文；mask、目标和损失含义 |
| 哪些参数变化 | 预训练/微调/部署分别冻结或更新什么，初始化与重置位置；内外循环适用时分别解释 |
| 如何优化 | 训练阶段、batch、长度、步数、优化器等论文实际披露的信息；梯度与状态传播边界 |
| 资源与成本 | GPU 型号与数量、训练时长、峰值显存、推理成本等；缺失项标未报告，不推算后冒充实测 |

Pair 回答“谁和谁匹配”，clip 回答“取一段多长的连续内容”，逐帧对齐又是另一件事。若论文没有要求逐帧匹配，不画隐含的一一对应箭头。

适用时做一个可点选的样本/时间线：每步显示正在读什么、状态如何变、哪个位置有监督、哪些参数更新。边界保持/重置和梯度停止分别标出。它是从方法重建的教学示意；除非官方公开了对应素材，不能称为“论文原始训练 pair”。没有在线更新的论文，不加入记忆或在线学习动画。

## 结果与边界

关键数值给出指标名称、单位、数据集/任务、基线和分母；把相对提升与百分点分开。若用 6/10 这类小样本结果，保留分子分母。成功演示是案例，不能替代统计成功率。图表切换时同步轴、说明和数值，不保留上一种条件的口径。

说明 baseline 是否同数据同预算、消融支持了哪个组件、哪些泛化没有测试。负结果和条件限制与正结果同样可见。不能从作者未分离的实验中分配各模块的独立贡献。

每个主要机制图、公式或结果附近放来源。优先使用论文页码、§、Eq.、Fig.、Table 或官方永久链接。外部背景解释有自己的出处；不要把版本不匹配的配置悄悄并入原文。

`SOURCES.md` 可用以下简单表格，并另列媒体文件来源：

| 网页位置 | 主张/对象 | 类型 | 依据 | 补充说明 |
| --- | --- | --- | --- | --- |
| #method | 关键连接与公式 | 原文事实 | PDF 第 X 页，Fig. Y / Eq. Z | 版本 |
| #training | 用于解释的三步序列 | 教学示意 | 依据 §X 重建 | 并非公开训练样本 |
| #resources | 某资源值缺失 | 未报告 | 查正文与附录 | 未以默认配置补齐 |

保留非官方中文导读与原作者署名；摘要以自己的话表达。原创机制图说明是重绘；引用图片/媒体保留出处和已知许可，不虚构许可声明。
