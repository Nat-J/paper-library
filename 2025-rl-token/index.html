RL Token

在冻结的视觉-语言-动作模型（VLA）内部训练一个紧凑表示，让小 actor-critic 在真实机器人上做数分钟级的在线强化学习。

一句话主线：预训练 VLA 提供感知与“初始动作建议”，RL token 把它的高维内部特征压缩成 RL 可用的状态；在线 RL 只在这个小表示上局部精修 VLA 的动作块，而不是从零学起。
π0.6 基座动作块 C=10稀疏 +1 奖励4 个精密任务提速最高 ~3×

关键数字（原文口径）

  • 螺钉安装关键阶段成功率 20% → 65%（摘要示例）。
  • 整任务评估中，螺钉成功率提升到 +40%，扎带 +60%（相对提升）。
  • 以太网任务上，RLT 的中位 episode 长度 66 步，优于遥操作示范中位 146 步（Fig. 9）。
  • 以太网任务只消费约 5 分钟关键阶段数据后性能超过基线（Fig. 7 说明）。
00

全貌：从 VLA 内部特征到在线 RL 策略

先沿箭头看一遍运行路径。橙色标号为后文展开的定位点，不是说训练按这个顺序“串行”。

整个系统分工明确：冻结的 VLA负责广泛感知和动作建议；RL token把它的内部知识压缩成小状态；轻量 actor-critic只负责在关键阶段把动作“往更成功的方向局部编辑”。

来源：PDF 第 1 页 Figure 1；第 3–5 页 §III–§IV；第 5 页 Algorithm 1。
01

问题：精度任务卡在“最后一毫米”

VLA 能“开箱即用”完成大量操作，但在需要毫米级对齐的阶段会变慢、反复试探，甚至失败。在线 RL 想补上这一段，但真实机器人每次试错都有时间与磨损成本。

常规做法 A：全模型 RL

对十亿参数级 VLA 做在线更新，计算与样本都开销巨大，难以在数小时内完成（§I、§IV-A）。

常规做法 B：小模型从零 RL

SERL 类方法用小 actor-critic 从零训练、配标准 ResNet 视觉编码器，几小时能学会，但丢掉了 VLA 的泛化先验（§II）。

方法只在每个任务的关键阶段（插入、紧固或旋转段）做 RL，其余由基座 VLA 完成。关键阶段通常持续 5–20 s（50 Hz 下约 250–1000 控制步），整任务 30–120 s。

来源：PDF 第 1 页摘要与 §I；第 7 页 §VI-A；第 9 页 §VI-C Q4。
02

机制一：用编码器-解码器挤出 RL token

RL 需要一个“够小、又保留任务相关信息”的状态。做法是在 VLA 最终层 token 序列末尾加一个可学习的 <rl> 嵌入，让编码器输出该位置的 zrl，再用解码器从 zrl 自回归重建原 token 嵌入，形成信息瓶颈。

zrl = gϕ([z1:M, erl])M+1     (1) Lro(ϕ) = ED[ Σi=1..M ‖ hϕ( dϕ([zrl, z̄1:i−1]) )i − z̄i ‖² ]     (2)
白话：zrl 是“压缩中间人”。它必须窄到够小，又必须大到让解码器能把 VLA 的 token 嵌入恢复出来。训练时 VLA 对 Lro 冻结（θvla 不因重建损失更新，可选地加一个 αLvla 项做监督微调）；训练完成后 VLA 与 token 模块一起冻结。

变量追踪

z1:M
VLA 最终层 → 编码器输入 → 解码重建目标
是什么：预训练 VLA 对状态 s 与指令 ℓ 产生的最终层 token 嵌入，按 token 切成 M 个。原文强调“each transformer layer 的嵌入都是高维”，选哪层特征并不显然，这里用最终层。
补充：实验里每任务语言指令固定，因此这一步省略语言嵌入（脚注 1）；一般构造仍适用于全部 VLA 嵌入。
erl = eϕ(<rl>)
可学习参数 → 拼到序列末尾
是什么：一个随 ϕ 一起训练的嵌入，占据序列第 M+1 个位置，让编码器在这个位置聚合整个序列再读出。
zrl
编码器读出位置 M+1 → 在线 RL 的输入状态一部分
是什么：1×2048 的向量（Fig. 2 标注），原始分辨率 token 是 N×2048。它同时是解码器自回归的起点，也是后面演员/评论家看到的“VLA 知识”载体。
下游：与本体状态 sp 拼成 x。
z̄i = sg(zi)
VLA 嵌入 → stop-gradient → 解码目标
是什么：重建目标。stop-gradient 意味着重建损失不会反向去改 VLA 的嵌入（θvla 只在可选的 VLA 微调项里更新）。
展开：用一个小数值例子理解重建损失

假设只有 2 个目标嵌入，一维简化表示：z̄1=2，z̄2=−1。

解码器第 1 步以 zrl 为条件，输出预测 ẑ1=1.5；第 2 步以 [zrl, z̄1=2] 为条件输出 ẑ2=−0.2。
误差项：(1.5−2)² = 0.25；(−0.2−(−1))² = 0.64。
Lro = 0.25 + 0.64 = 0.89。每个样本对 M 项求和后取期望；梯度只回传到编码器/解码器参数 ϕ。

这个例子说明：zrl 必须携带足够信息，否则无论解码器多强，第一步预测就会偏；解码器越强、zrl 越窄，瓶颈就压得越紧。这是一维教学简化，实际 token 是 2048 维向量。

训练 token 时用少量单任务示范数据：原文附录 B 说先收集任务示范数据，然后对基座 VLA 微调并训练 RL token，共 2000–10000 梯度步；随后 VLA 冻结。

来源：PDF 第 4 页 §IV-A、Eq. (1)(2)、Figure 2；第 12 页附录 B。
03

机制二：演员在 VLA 建议附近做局部编辑

与“输出残差”或“在噪声空间操控扩散”的方法不同，RLT 的演员直接以 VLA 采样出的动作块为条件，并在目标函数里显式拉回它。在线 RL 因此变成对好先验的局部修正。

对照方法（原文 §II 描述）

单步残差类（PLD、Policy Decorator、ConRFT 等）：在冻住 VLA 上输出单步残差或一致性目标，horizon 很长。
DSRL / GR-RL 类：在扩散噪声空间学策略，用潜变量“转向”去噪过程，探索被隐式限制在 VLA 能生成的模态内。

RLT 的路径

改演员直接输出 C=10 的动作块；增输入包含 VLA 参考动作块 ṽa；增损失里加 β 范数正则；增训练时随机把 ṽa 置零（50%）防止照抄。评论家在整个动作块上做 TD，缩短稀疏奖励下的信用分配。

两个网络的输入和目标是：

πθ(a1:C | x, ṽa1:C) = N( μθ(x, ṽa1:C), σ²I )     (4) LQ(ψ) = EB[ ( Q̂ − Qψ(x, a1:C) )² ]，Q̂ = Σt′=1..C γt′−1rt′ + γCEa′∼πθ[ Qψ′(x′, a′) ]     (3) Lπ(θ) = E[ − Qψ(x, a1:C) + β ‖a1:C − ṽa1:C‖²2 ]，  ṽa1:C ∼ πvla(·|s, ℓ)     (5)
x
RL 状态：x = (zrl, sp)，含 RL token 与本体状态
a1:C
RL 动作块，C=10 步，每步 14 维动作，共 140 维向量
ṽa1:C
VLA 采样的参考动作块（RL 设长 C 的部分）
ψ, ψ′
评论家参数与目标网络参数；双 Q 集成取最小值
β
BC 正则强度；消融时设 β=0
γ
折扣因子
展开：一个动作块的 TD 目标怎么算（数值演示）

为便于手算，假设 C=2、γ=0.9，两个子步奖励都是 0，终止前没有成功，最后下一状态的 Qψ′ 期望值估为 3。

Q̂ = γ0r1 + γ1r2 + γ2·E[Qψ′(x′,a′)]
= 0 + 0 + 0.81 × 3 = 2.43
若当前评论家对这段动作块估计 Qψ=1.9，则 TD 误差 = 2.43 − 1.9 = 0.53，平方后 0.28 作为该样本损失。

这个演示把 C 缩到 2、忽略奖励项，只展示“块级 TD”里折扣与 bootstrapping 的组合方式；论文实际 C=10、奖励是末端稀疏 +1，未报告中间奖励。

为什么正则项消融影响最大？原文 Q3 汇报：去掉 BC 正则（β=0）是单项最大跌幅，因为演员只剩 Q 函数梯度，要在整个高维动作块空间里搜索。参考动作 dropout 则是另一层保险：防止演员过早只会照抄 ṽa。

05

证据：成功率、吞吐与超出示范的速度

原文在“关键阶段受控评测”（每任务 50 episodes）与“整任务评测”（螺钉、扎带）两套设定下比较。下面只列文字中明确给出的口径。

Q1 相对基座 VLA

四任务关键阶段均提升；以太网与充电器约 3× 更快；螺钉关键阶段成功率 20% → 65%；整任务成功率螺钉 +40%、扎带 +60%（相对提升）。

Q2 对比其它 RL 方法

以太网任务上，单步方法 HIL-SERL 与 PLD 无法有效学习；DAgger 与 DSRL 成功率接近 RLT，但提速明显更少；RLT 把完成所需平均步数相对基座 减半。

消融（以太网任务，Fig. 7–8）

  • 去掉 RL token（换冻结 ImageNet ResNet-10）：吞吐下降约 50%，说明 token 编码了通用视觉编码器没有的操作结构。
  • 去掉分块（C=1）：有效 horizon 拉长、信用分配变难，实际上无法可靠追平基座策略。
  • 去掉 BC 正则（β=0）：单项最大跌幅。
  • 去掉参考动作透传：学习更慢、早期探索漂移，偶有退化的行为；在该任务最终可追平，但训练过程中失败更多。

另有定性结论：以太网任务上，RLT 策略的中位长度 66 步，快于全部遥操作示范（中位 146 步）；原文称一半 RL 回合比所有示范都快。

来源：PDF 第 1 页摘要；第 6–9 页 §VI-B–§VI-C、Figs. 4–9；第 12 页附录 B。

边界与回读

这些限制与未报告项和正结果同样重要，阅读时不要拿常识补全。

  • 依赖人工：训练需要人提供奖励、干预纠正，以及决定何时从基座切到 RL；原文把自动化（奖励模型、进度预测）列为未来方向。
  • 评测范围：关键阶段受控评测每任务 50 episodes；整任务评测只覆盖螺钉与扎带两个较难任务。充电器与以太网没有整任务数字。
  • 未报告：GPU 型号/数量、墙钟训练时长、单次推理耗时、β 的具体取值、σ 的具体数值，正文均未给出。
  • 依赖基座：方法假定预训练 VLA 已经“足够好”，RL 只做局部精修；若 VLA 提议系统性错误，正则项也可能限制改进。
  • 原文页码：本导读使用 PDF 页序（1–13），与部分印刷版页码可能不同。
